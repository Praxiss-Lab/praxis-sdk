# TypeScript client

The TypeScript client talks to a Praxis [Agent Server](../guides/agent-server.md). It
mirrors the Python SDK structure but supports only remote conversations, and it is
browser-compatible.

> [!WARNING]
> **Alpha**
> The client API may change between versions without notice.

- Source and full README: [`clients/typescript/`](https://github.com/Praxiss-Lab/praxis-sdk/blob/main/clients/typescript/README.md)
- Examples: [`clients/typescript/examples/`](https://github.com/Praxiss-Lab/praxis-sdk/tree/main/clients/typescript/examples)
